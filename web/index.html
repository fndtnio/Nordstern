Read this before quoting anything. Every number on this page is derived from entities/*.yaml by check.py at build time — the page owns no calculation of its own, so the charts cannot drift from the register. What it can do is show you a well-formed number computed from an unverified one; see the banner above.
Some figures here carry no link, and that is deliberate. The query language counts records. Blockers, moved entries and actor mentions are not records, so no query returns those numbers — the first version of this page linked them to a plausible-looking query anyway and printed 127 beside a query returning 54. A test now compares every linked figure against its own query on every build.
Snapshots are frozen on every build into web/snapshots/, so a later pass is a comparison rather than a fresh opinion.
Disease identifiers are borrowed from Mondo, never minted. The only identifiers this project creates are for its own assertions — the rating is the new thing, so the rating gets the address.
