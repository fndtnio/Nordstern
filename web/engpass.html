Engpass reads Nordstern's built artifact and never the reverse — the dependency runs one way, and Engpass/test_boundary.py enforces it rather than trusting it. Nordstern records blockers[].obstacles and does not validate the slugs; this register reconciles them. The disease list under each obstacle is derived, never stored, because a blocker is a claim about that disease made by whoever rated it — and a link stored in two files is a link that can disagree with itself.
